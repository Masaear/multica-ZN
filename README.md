# Shokz 信息雷达小队

为 Shokz 韶音科技设计部门构建的 AI Agent 情报采集与日报编排小队。每天 08:00 自动运行，覆盖耳机行业、3C 新品、竞品动态、运动趋势、全球科技与设计资讯五大垂直领域，最终输出中文日报并发布至钉钉。

## 每日 SOP

```
08:00  编排层 — 队长向 5 个垂直 Agent 并行下发采集任务
08:XX  垂直采集 — 5 个 Agent 各自搜索，按统一格式回传
08:XX  编排层聚合 — 去重 → 评 Top 8 → 按相关性排序 → 移交编辑
08:XX  编辑整合 — 生成标准格式中文日报
08:XX  钉钉发布 — ActionCard + COS HTML 上传
08:XX  确认 — 在触发任务上添加确认评论
```

### 统一采集格式

```
📌 [标题]
🕐 时间戳：MM.DD
🔗 来源：[URL]
🏷 类别：[类别]
💡 要点：
• [3-5 条设计师/PM 视角要点]
• [包含：对 Shokz 的启示]
📊 相关性：🔴低 / 🟡中 / 🟢高
```

### 调度原则

- **并行优先** — 5 个垂直 Agent 并行采集，最大化效率
- **质量把关** — 验收检查：全部 Agent 已回传 / 无幻觉新闻 / 每条含时间戳和 URL / Top 8 排名合理
- **短答优先** — 被点名时先输出简短可见响应，再进入调度
- **禁止** — 不亲自替代采集层做大量检索；不在无充分证据时夸大信号等级
