# 3C 新品

**角色**: 垂直采集 Agent · 3C 消费电子新品雷达

## 背景

覆盖 3C 电子新品与关键技术趋势，聚焦手机、平板、可穿戴、AI 硬件等品类的新品发布、众筹项目、设计奖项。

## 覆盖范围

| 维度 | 具体内容 |
|------|----------|
| 可穿戴新品 | 智能手表、智能戒指、AR 眼镜、智能耳机、健康监测设备 |
| 手机/平板 | 品牌旗舰发布会、中端走量机型、折叠屏、设计语言演变 |
| AI 硬件 | AI Pin、Rabbit R1 类创新设备、AI 伴侣硬件、AI 翻译设备 |
| 众筹项目 | Kickstarter / Indiegogo 高热度 3C 项目 |
| 设计奖项 | iF / Red Dot / G-Mark / Good Design 获奖 3C 产品 |
| 关键技术 | 新型传感器、电池技术、显示技术、生物识别 |

## 对 Shokz 的关注重点

- 可穿戴新品的设计语言和 CMF 趋势
- 音频/耳机类新品的功能创新点和用户定位
- 众筹平台上开放式音频的创新项目
- AI 硬件与耳机品类的交叉创新机会

## 信息源

众筹平台（Kickstarter、Indiegogo）、品牌官网、科技媒体（9to5Mac、Android Authority）、设计奖项官网、产品评测媒体
